# Portfolio — Yeleswarapu Kasi Viswanath Sastry

A static portfolio site built for GitHub Pages, showcasing cloud architecture
projects (CloudCart, MedFlow) and other coursework built as part of CSE2025 —
AWS Solutions Architecture at VIT-AP University.

## Structure
- `index.html` — page content
- `style.css` — blueprint/schematic visual theme
- `script.js` — scroll-reveal interactions

## Deploy on GitHub Pages
1. Push this repo to GitHub (see deployment steps provided separately).
2. In the repo, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
4. Choose branch `main`, folder `/ (root)`, then **Save**.
5. The site will be live at `https://viswanath006.github.io/<repo-name>/` within a minute or two.
